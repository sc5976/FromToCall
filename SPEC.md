# FromToCall — Калькулятор рабочего времени

## Концепция и видение

Минималистичное приложение-таймер для учёта рабочего времени. Сотрудник один раз вводит время прихода, приложение рассчитывает время ухода с учётом обеда и «пятничного графика». В фоне работает сервис, который в нужный момент подаёт звуковой сигнал — «Иди домой!». Никаких лишних экранов, только главный и настройки.

## Дизайн

- **Эстетика**: чистый Material Design 3, тёмная тема по умолчанию
- **Палитра**:
  - Primary: #4CAF50 (зелёный — «пора уходить»)
  - Secondary: #FF9800 (оранжевый — предупреждение)
  - Background: #121212
  - Surface: #1E1E1E
  - OnSurface: #FFFFFF
- **Типографика**: Roboto, крупные цифры для времени (48sp)
- **Иконки**: Material Symbols Rounded

## Структура экранов

### Главный экран
- Верхняя карточка: сегодняшняя дата, день недели
- Блок «Время прихода» — выбор часов и минут (NumberPicker или custom wheel)
- Блок «Время ухода» — рассчитанное, readonly, крупно
- Прогресс-бар: сколько осталось работать
- Кнопка «Сброс» (крестик в углу)

### Экран настроек
- Рабочий день (полный): часы и минуты (по умолчанию 8:45)
- Рабочий день (пятница/сокращённый): по умолчанию 7:45
- Время обеда: по умолчанию 1:00 (один час)
- Выбор звука уведомления (список предустановленных)
- Тест звука

## Логика расчёта

```
ВремяУхода = ВремяПрихода + РабочийДень - Обед
```

- Если сегодня пятница → сокращённый рабочий день
- Суббота/воскресенье → не работаем (00:00)
- Обед вычитается только если рабочий день > 4 часа

## Фоновый сервис

- Foreground Service с постоянным уведомлением «Идёт рабочий день»
- При достижении времени ухода:
  1. Запускается AlarmManager
  2. Показывается уведомление-«Иди домой!» с vibrate
  3. Воспроизводится выбранный звук
- Service перезапускается после перезагрузки
