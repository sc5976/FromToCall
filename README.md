# FromToCall

**[🇬🇧 English version](README.en.md)**

Android-приложение для учёта рабочего дня. Указываешь время прихода — приложение
считает время ухода по длительности дня и в нужный момент подаёт сигнал
«пора уходить». Звук, вибрация, уведомление — три независимых способа напомнить.

## Что умеет

### Учёт времени

- **Четыре независимых длительности по дням недели**: понедельник–четверг,
  пятница, суббота, воскресенье — у каждой своя полная длительность. Никаких
  автоматических вычетов («обед 1 час» и т. п.): пользователь задаёт
  значение целиком. Суббота и воскресенье — отдельные настройки, не
  одна общая «выходные».
- **Время прихода** автоматически ставится в текущее при запуске, если таймер
  ещё не запущен. Можно отредактировать и нажать «Старт».
- **Таймер** запоминает время прихода в `SharedPreferences`. Если процесс
  принудительно остановлен, при следующем открытии приложение восстанавливает
  тот же приход и переставляет будильник заново.

### Сигнал ухода

- **Звук + вибрация + уведомление** — три независимых способа напомнить.
  В постоянном уведомлении показывается обратный отсчёт
  («Уход в 21:50 • осталось 7 ч 44 мин»), обновляется раз в 30 секунд.
- **Громкость `STREAM_ALARM`** поднимается до максимума на время звонка
  и возвращается к исходной, когда сигнал выключают. Это лечит «вибрация есть,
  звука нет» из-за отдельной регулировки потока будильника в настройках
  Android.
- **Авто-стоп через 60 секунд** на случай, если телефон не с вами.
- **Кнопка «Отключить»** в самом уведомлении и в приложении (красная
  карточка появляется на главном экране, пока сигнал звонит).
- **Восстановление будильника после перезагрузки** телефона.

### Настройки

- **Длительности** для четырёх групп дней — четыре строки в настройках,
  тап открывает диалог с TimePicker.
- **Звук уведомления** — стандартный системный пикер Android.
- **Язык интерфейса**: системный, Русский, English. По умолчанию — Русский.
  Выбор применяется мгновенно, без перезапуска приложения.
- **Акцентный цвет** на выбор: зелёный (по умолчанию), синий, фиолетовый,
  оранжевый, бирюзовый, красный. Меняет карточку «Время ухода», таймер
  обратного отсчёта, акценты в кнопках. Схема остаётся тёмной.

## Требования для сборки

- **JDK 17** (Temurin / Zulu / Oracle — без разницы).
- **Android SDK 34** с build-tools 34.0.0 и platform-tools.
- **Gradle 8.4** — поставляется через `gradlew`, ставить в систему не нужно.

## Как собрать

```bash
# Release APK с автоприращением версии (1.0, 1.1, 1.2, …).
# Готовый файл ляжет в dist/FromToCall-release-<version>.apk.
./gradlew distRelease

# Debug-вариант для отладки на эмуляторе / устройстве.
./gradlew distDebug
```

Версия хранится в `version.properties`: `major` и `minor`. После каждого
успешного `assembleRelease` Gradle сам инкрементит `minor`. Если сборка
упала — номер не сдвигается, и следующий запуск попробует тот же `1.x`
заново. `versionCode` берётся из эпохи (секунды с 1970) и потому всегда
монотонно растёт — это нужно, чтобы Android согласился обновить
установленный APK поверх старого.

## Подпись релизов

В репозитории ключа нет — он локальный, лежит в `fromtocall-release.jks`.
Пароль — в `app/build.gradle.kts` в `signingConfigs.release`. Это нормально
для личного проекта, но перед публикацией в Google Play:

1. Сгенерируйте свой ключ (`keytool -genkeypair ...`).
2. Положите его рядом с проектом и обновите путь/пароль в `build.gradle.kts`.
3. Соберите заново.

Без этого шага обновления поверх установленной копии потребуют удаления
приложения — старая и новая сборка будут считаться выпущенными разными
разработчиками.

## Структура проекта

```
app/
  src/main/java/com/fromtocall/
    data/             # SettingsRepository — настройки в DataStore
    service/          # WorkTimerService, AlarmService, ресиверы
    ui/screens/       # MainScreen, SettingsScreen + ViewModel-ы
    ui/components/    # TimePickerWheel
    ui/theme/         # Theme, AccentPalette (палитра акцентов)
  src/main/res/       # strings, drawables, темы (RU по умолчанию, values-en для EN)
build.gradle.kts      # SDK, зависимости, signingConfig, dist-таски
settings.gradle.kts
version.properties    # major/minor, автоприращивается
```

## Что в каждом файле (коротко)

- `service/WorkTimerService.kt` — foreground-сервис, который держит
  постоянное уведомление с обратным отсчётом и переустанавливает будильник
  в `AlarmManager` (с поддержкой перезагрузки).
- `service/AlarmService.kt` — сервис самого звонка: wake lock,
  `MediaPlayer` со звуком, вибрация, авто-стоп через 60 с, временное
  поднятие `STREAM_ALARM`.
- `service/AlarmReceiver.kt` — маршрутизация `AlarmManager → AlarmService`.
- `service/StopAlarmReceiver.kt` — кнопка «Отключить» в уведомлении.
- `service/BootReceiver.kt` — переустановка будильника после перезагрузки.
- `ui/screens/MainViewModel.kt` — реактивный стор, пересчёт остатка по тику
  + по смене прихода/настроек.
- `ui/screens/SettingsViewModel.kt` + `SettingsScreen.kt` — четыре строки
  длительности (Пн–Чт / Пт / Сб / Вс), выбор звука, переключатель языка,
  палитра акцентного цвета.
- `ui/theme/AccentPalette.kt` — шесть пресетов акцентного цвета
  (зелёный, синий, фиолетовый, оранжевый, бирюзовый, красный).
